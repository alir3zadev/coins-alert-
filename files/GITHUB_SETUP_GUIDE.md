# راهنمای مرحله‌به‌مرحله: اجرای رایگان و ۲۴ساعته با GitHub Actions

با این روش، لازم نیست سیستم خودت روشن بمونه؛ GitHub هر ۱۵ دقیقه یک‌بار به‌طور
خودکار قیمت رو چک می‌کنه و در صورت نیاز به تلگرامت پیام می‌ده. کاملاً رایگانه.

---

## مرحله ۱: پیدا کردن chat_id تلگرام
1. در تلگرام برو سراغ ربات خودت و یک پیام (مثلاً `/start`) بهش بفرست.
2. در مرورگر این آدرس رو باز کن (توکنت از قبل جاگذاری شده):
   ```
   https://api.telegram.org/bot8684830528:AAHM2DS9bXtQNpXD9jOp_D0g2ntHT4GbhUU/getUpdates
   ```
3. در متنی که باز می‌شه، دنبال بخش `"chat":{"id":` بگرد. عددی که جلوش میاد
   همون **chat_id** توئه. اون رو جایی یادداشت کن.

## مرحله ۲: ساخت اکانت و ریپازیتوری در GitHub
1. اگه اکانت نداری، در github.com یک اکانت رایگان بساز.
2. روی دکمه‌ی سبز **New** (ساخت ریپازیتوری جدید) بزن.
3. یک اسم بذار، مثلاً `price-alert-bot`.
4. حتماً گزینه‌ی **Private** رو انتخاب کن (چون فایل تنظیمات داخلشه).
5. روی **Create repository** بزن.

## مرحله ۳: آپلود فایل‌ها
از داخل همین چت، این فایل‌ها رو دانلود کن:
- `check_price.py`
- `config.json`
- `state.json`
- `.github/workflows/check.yml`

سپس در صفحه‌ی ریپازیتوری‌ت:
1. روی **Add file → Upload files** بزن.
2. فایل‌های `check_price.py`، `config.json`، `state.json` رو بکش و ول کن (drag & drop).
3. برای فایل workflow، باید مسیر پوشه دقیقاً حفظ بشه: `.github/workflows/check.yml`.
   ساده‌ترین راه: در همون صفحه‌ی آپلود، کل پوشه‌ی `.github` (شامل زیرپوشه‌
   `workflows` و فایل `check.yml`) رو بکش و رها کن — گیت‌هاب ساختار پوشه رو
   حفظ می‌کنه.
4. پایین صفحه روی **Commit changes** بزن.

## مرحله ۴: اضافه‌کردن رمزهای امنیتی (Secrets)
توکن ربات و chat_id نباید داخل کد یا فایل‌های عمومی باشن؛ اینا رو جدا و
امن ذخیره می‌کنیم:

1. در ریپازیتوری، برو به **Settings**.
2. از منوی سمت چپ: **Secrets and variables → Actions**.
3. روی **New repository secret** بزن:
   - Name: `TELEGRAM_TOKEN`  
     Value: `8684830528:AAHM2DS9bXtQNpXD9jOp_D0g2ntHT4GbhUU`
   - دوباره **New repository secret** بزن:
   - Name: `CHAT_ID`  
     Value: همون عددی که در مرحله ۱ پیدا کردی

## مرحله ۵: فعال‌کردن دسترسی نوشتن برای Actions
1. همچنان در **Settings**، برو به **Actions → General**.
2. پایین صفحه، بخش **Workflow permissions** رو پیدا کن.
3. گزینه‌ی **Read and write permissions** رو انتخاب کن و **Save** بزن.
   (این لازمه چون اسکریپت باید فایل `state.json` رو برای جلوگیری از
   اسپم‌شدن پیام‌ها، به‌روزرسانی و ذخیره کنه.)

## مرحله ۶: تست دستی
1. برو به تب **Actions** در بالای صفحه‌ی ریپازیتوری.
2. روی workflow با نام **Price Alert Check** کلیک کن.
3. سمت راست دکمه‌ی **Run workflow** رو بزن تا همین الان یک‌بار اجرا بشه.
4. بعد از چند ثانیه، روی اجرای انجام‌شده کلیک کن و لاگ‌ها رو ببین — باید
   قیمت فعلی کوین چاپ شده باشه. اگه قیمت داخل محدوده‌ت بود، باید پیام
   تلگرام هم دریافت کرده باشی.

از این به بعد، این workflow **خودکار هر ۱۵ دقیقه** اجرا می‌شه، بدون این‌که
نیازی به باز بودن سیستم یا مرورگرت باشه.

---

## چطور کوین یا محدوده قیمت رو عوض کنم؟
1. در ریپازیتوری، وارد فایل `config.json` بشو.
2. روی آیکون مداد (ویرایش) بزن.
3. مقدار `coin_id`، `low_price` یا `high_price` رو تغییر بده.
4. **Commit changes** بزن. تغییرات از اجرای بعدی اعمال می‌شه.

برای پیدا کردن شناسه‌ی (`coin_id`) هر کوین: اسمش رو در coingecko.com سرچ کن؛
شناسه در آدرس صفحه (بعد از `/coins/`) نمایش داده می‌شه. مثال‌ها:
`bitcoin`, `ethereum`, `ripple`, `dogecoin`, `solana`.

## نکته درباره‌ی فاصله‌ی زمانی چک
در فایل `.github/workflows/check.yml` مقدار `cron: "*/15 * * * *"` یعنی هر
۱۵ دقیقه. اگه بخوای مثلاً هر ۵ دقیقه چک بشه، این خط رو به `*/5 * * * *`
تغییر بده (کمتر از این مقدار معمولاً توسط GitHub قبول نمی‌شه یا محدود
می‌شه).

## نکته امنیتی
چون توکن رو داخل Secrets گذاشتی (نه داخل کد)، حتی اگه ریپازیتوری Public
هم بود لو نمی‌رفت؛ ولی بازم بهتره Private نگهش داری.
